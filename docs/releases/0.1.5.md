# Noltri 0.1.5

0.1.5 面向 Apple Silicon Mac，支持 macOS 13.5 及更新版本。本版修复原生选区浮层重复出现和扩展键盘选区，并让待发送内容在 Chrome 保持打开、Core 恢复后自动重试。人工确认的资料可在统一搜索中找到并打开阅读。

## 全新安装

从对应的 Release 下载 `Noltri-0.1.5-macos-arm64.dmg` 和 `SHA256SUMS.txt`。核对 DMG 的 SHA256 后，打开 DMG 并把「知序」拖入「应用程序」。[GitHub Releases](https://github.com/wyzh0117/noltri/releases)

App 使用 ad-hoc 签名，无 Apple Developer ID 签名和公证。发行预检 `syspolicy_check distribution` 由于缺少公证票据未通过。默认 Gatekeeper 下的实际安装与首次启动未验证，macOS 首次打开时可能警告或阻止启动。确认发布来源和校验值后，可参考 Apple 对单个 App 的安全打开指引。若系统报告文件损坏或恶意内容，请停止安装。[Apple 支持](https://support.apple.com/en-us/102445)

Chrome 扩展在 Release 中单独提供。核对 `noltri-extension.zip` 的 SHA256 并解压，在 `chrome://extensions` 启用开发者模式，点击「加载已解压的扩展程序」并选择含 `manifest.json` 的目录。

发布资产包含项目签名的 Tauri 更新归档和更新清单。项目更新签名独立于 macOS 发行签名。本版验收范围为全新安装。[应用内更新](../application-updates.md)
