# 知序 0.2.0

发布日期：2026-10-24。目标平台为 Apple Silicon（arm64），要求 macOS 13.5 或更新版本。

0.2.0 为 Notes 与 Graph 工作台重构版本。笔记正文以本地 Markdown Vault 文件为真相，索引可重建；旧知识库与采集入口继续保留。

## 主要变化

- 新增 Vault 文件树与 Markdown 笔记工作台，支持文件和文件夹管理、属性、链接、反链、未链接提及、历史版本与冲突保护。
- 新增 CodeMirror Live Preview。编辑器根据光标、选区和搜索命中显示源码，其余 Markdown 内容即时渲染；阅读视图按 section 渐进加载，支持标题、block、脚注与嵌入跳转。
- 新增面向同一 Markdown Vault 的关系图，支持全局/局部浏览、标签节点、查询过滤、分组、持久化布局和 PNG 导出。
- 旧笔记编辑接口映射到 Markdown Vault，保存使用 etag 并发保护，避免 SQLite 正文与 Markdown 正文形成两个独立真相。

## 验证状态与已知限制

本轮源码检查通过：knowledge-core 224 项、desktop 107 项、API client 33 项、MCP server 19 项测试及相应 typecheck。Notes 长时输入 run 超过 30 分钟；连续输入与最终 Markdown 文件完整性检查通过，但 raw runner 因收尾状态仍处于 indexing 标记为 invalid，后续只读状态显示已保存。该结果不证明 UI 内部 etag 与 Core etag 精确一致。

性能预算尚未达标：5,000 行 Live Preview 长测 `beforeinput→next-rAF` p95 为 39.8ms（目标 <16ms），最大值 320.8ms；5,000 节点、10,000 条边的浏览器 Graph Worker 收敛约 4.165s（目标 <2s）。Reader 10,000 行滚动帧预算仍未测。Core、Editor、Graph 的已验证范围与未覆盖交互见[验收记录](../testing/vault-notes-graph/acceptance.md)。

macOS 构建采用 ad-hoc 签名，没有 Apple Developer ID 签名或公证；Gatekeeper 可能拦截首次打开。请在下载后使用 GitHub Release 的 `SHA256SUMS.txt` 校验安装包，并遵循 [README 的首次打开说明](../../README.md)。
