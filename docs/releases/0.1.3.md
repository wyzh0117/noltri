# 知序 0.1.3

日期：2026-10-21。面向 Apple Silicon（arm64），要求 macOS 13.5 或更新版本。

## 变更摘要

- D01：保留既有 MemoryCard 展示和资料信息层级；相关桌面入口与样式在 apps/desktop/src/workbench/WorkbenchApp.tsx、workbench.css。
- D02：主题概览和章节正文在中间区域直接阅读、编辑；Graph 只在右侧展开，点击节点更新正文；相关实现位于 GraphNotebook.tsx、WorkbenchApp.tsx、workbench.css。
- D03：右侧面板仅承担 Graph 及其必要操作，Graph 收起时提供展开入口；renderer 与操作位于 WorkbenchGraph.tsx、workbench-graph.css。
- D04：Graph 使用真实节点和关系、圆点与细线、密度标签、键盘／指针交互及 Obsidian 行为参照；相关代码位于 WorkbenchGraph.tsx、workbench-graph-view.ts、workbench-graph-layout.ts、workbench-graph-state.ts 和 workbench-graph.css。
- D05：一级／二级学科入口都可展开相应范围；Graph selection、章节解析和范围交互位于 WorkbenchApp.tsx、api.ts、packages/api-client/src/client.ts、services/knowledge-core/src/services/graph.ts。

主题概览及章节正文独立持久化在 knowledge_notes；SQLite schema v7 新增笔记表和索引。v6 → v7 fixture 验证原来源、nodes、edges、knowledge items 和 links 保留，本轮迁移不改写这些旧记录。Graph API 使用稳定 ID 关联；本次不改变采集原文与章节关系的存储语义。

继续支持 0.1.2 的 Provider 管理：OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages；Apply 保存配置，“使用此模型”设置自动处理内容所用模型。

## 已知限制

- 正文上限为 40,000 JavaScript 字符。
- Graph 最多绘制 260 个节点；完整范围仍参与搜索，超过上限的节点可由搜索命中并加入当前绘制窗口。
- 极长 selected label 在画布边缘会裁切；搜索结果行与正文仍可读。
- A15 缺少待整理层级选择、章节 hover/focus 提示及完成后的定位／撤销完整流程；A16 缺少来源复用、独立论文研究页、显式幂等转入和掌握诊断完整能力。这些是 0.1.2 HEAD 基线缺项，详见 [基线回归](../testing/graph-v3.1/baseline-regression.md)。
- F05 覆盖／缺口诊断、F06 桌面会话入口未实现；桌面修改历史读取不完整，当前没有版本读取 API/service route。
- 本次发布采用 ad-hoc 签名，没有 Developer ID 签名或 Apple notarization。spctl 结果为 rejected；签名完整性通过不等于 Gatekeeper 接受。macOS 首次打开说明须保留。
