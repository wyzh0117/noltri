# 知序 0.1.1

支持 Apple Silicon（arm64），要求 macOS 13.5 或更新版本。

- 由配置的 AI 判断收集片段的知识体系与分层分类；支持修改原文、标题、分类和研究点，人工分类优先保留。未配置模型时保存原文等待整理，模型失败可重试。
- 首屏改为模型设置；知识库内可再次打开设置，添加多组模型并通过下拉框切换。保存后重启应用管理的本机服务，外部服务则明确提示需自行重启。
- 修复 0.1.0 缺失应用资源封印和随包运行时签名无效的问题。构建会验证 DMG 内实际应用的签名、SQLite 与 JIT；DeepSeek 的结构化提取和分类请求关闭默认思考模式，避免推理占用短 JSON 输出额度。

## 下载

- `noltri-0.1.1-macos-arm64.dmg`：打开后将“知序”拖入 Applications。
- `noltri-0.1.1-macos-arm64.zip`：同一应用的压缩包。
- `noltri-extension.zip`：Chrome 扩展，解压后在扩展管理页选择“加载已解压的扩展程序”。
- `noltri-0.1.1-test-results.zip`：测试片段、实际结果和验证说明；不包含测试密钥或本机资料库。
- `SHA256SUMS.txt`：下载文件校验值。

## 首次打开

本次按用户选择发布 **ad-hoc 签名、未通过 Apple 公证** 的版本。包内签名完整性已修复，Gatekeeper 仍可能拦截首次打开，这不等于通过 Apple 分发审核。

先对照 `SHA256SUMS.txt` 校验下载文件，再按 [Apple 官方指引](https://support.apple.com/en-us/102445)选择“系统设置 → 隐私与安全性 → 仍要打开”。若仍显示“已损坏”，确认下载来源和校验值后，可按顺序执行：

```bash
codesign --verify --deep --strict "/Applications/知序.app"
xattr -dr com.apple.quarantine "/Applications/知序.app"
open "/Applications/知序.app"
```

只有第一条验签成功后才执行后两条；命令仅针对知序，不关闭系统的 Gatekeeper。免手动批准的分发仍需 Developer ID 签名和 Apple 公证。

## 验证

全仓 523 项自动测试、10 个工作区类型检查、5 项 Rust 测试通过。真实 DeepSeek Flash 回归覆盖 Python、TypeScript、Rust、Go、SQL 和物理、计量经济学、分子生物学、心理学论文短摘录，9/9 通过；人工修改原文、标题、分类及研究点后重新读取验证通过。DeepSeek Pro 另有真实分类与失败原文重试检查。

测试输入、结果及范围见[测试说明](https://github.com/wyzh0117/noltri/tree/v0.1.1/docs/testing)。模型表单做了渲染与原生配置检查；实际配置切换通过本机 profile 文件和安装版重启验证，未执行 GUI 点击验收。本机应用保留测试资料及结果，安装包不携带这些本机数据。
