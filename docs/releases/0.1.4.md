# 知序 0.1.4

日期：2026-10-22。目标平台为 Apple Silicon（arm64），要求 macOS 13.5 或更新版本。候选构建及正式安装版升级验收已通过；此版本将随 annotated v0.1.4 tag 发布。

## 变更摘要

- 修复旧分类根节点无法打开 Graph 的问题。Tree 和 Graph 将遗留根级、二级 `domain` 兼容呈现为 `discipline`、`subdiscipline`，沿用原节点 ID 与存储类型。
- 手工与 AI 分类 writer 共用新的路径层级约定：多级路径写入 `discipline / subdiscipline / domain… / topic`；单级分类仍为根级 topic。无数据库 schema 迁移，不新增依赖。

完整缺陷过程和升级记录见[发布验收报告](../reports/0.1.4-defect-discovery-upgrade-and-collection.md)及[分类兼容验收](../testing/0.1.4/acceptance.md)。

## 数据兼容与升级

原位升级后应用版本为 0.1.4；升级前的 1 条 source、1 条 knowledge item 和 1 个 topic 保持不变。正式版 Library 中进入“数学 / 概率论”并展开 Graph 后，原有叶节点成功显示；About 显示 0.1.4。逐项结果和截图哈希见[升级结果摘要](../testing/0.1.4/upgrade-results.json)。

旧 domain 分类的 HTTP／SQLite 兼容、Graph 学科范围和授权路径由[独立验收记录](../testing/0.1.4/acceptance.md)验证。正式应用升级截图与结果 JSON 已包含在本次测试证据中。

## 签名和已知限制

应用采用 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证。`spctl` 因此 rejected；签名完整性通过不表示 Gatekeeper 接受。macOS 首次打开说明沿用[0.1.3 发布说明](0.1.3.md)。

Graph 与知识编辑的已知边界沿用 0.1.3：正文上限 40,000 JavaScript 字符；Graph 绘制上限 260 个节点；极长 selected label 可能在画布边缘裁切；F05 覆盖／缺口诊断和 F06 桌面会话入口未实现；桌面修改历史读取不完整。详细验收范围见 [Graph v3.1 A01–A16 矩阵](../testing/graph-v3.1/acceptance.md)。
