# 知序 0.1.2

支持 Apple Silicon（arm64），要求 macOS 13.5 或更新版本。

- 模型设置改为 Provider 管理，可配置 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages。
- Provider 可拉取候选模型或手动添加模型；Apply 保存配置，“使用此模型”预先设置全局活动模型。
- API 密钥仅写入本机配置，不在读取配置时返回。
- 界面与操作参考 [DeepSeek Harness v0.2.1-alpha.3](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-alpha.3)，本版本范围限于上述三种通用 API 协议。
